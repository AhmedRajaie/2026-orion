# learn/ — instructor material (the first part of each day)

Three tracks, plus a glossary in the repo root (`CONCEPTS.md`).

- `00-getting-started/` — Day 1 setup + repo tour
- `01-stock-market/` — 5 HTML sessions: basics, landscape, participants, charts, companies
- `02-algo-trading/` — 8 HTML parts (0–7): from "what is an algorithm" to "what AI brings"
- `03-quant-and-ai/` — 7 HTML concept pages, one per idea:
  - `indicators` (wk1) · `risk-and-volatility` (wk2) · `neural-nets-no-math` (wk2)
  - `portfolio-theory` (wk2) · `walk-forward` (wk2–3) · `mdp-and-agents` (wk3)
  - `reinforcement-learning` (wk3)

Every page is a self-contained HTML file — open it in any browser. They match the
Stock-Market and Algo-Trading series in style, so the whole set feels like one
course. Fonts and any charts load from a CDN, so keep internet on in the room.

Each `weekN/dayX/README.md` points to the exact page(s) for that day's talk.
