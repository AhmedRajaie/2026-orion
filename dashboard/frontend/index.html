Strategy performance comparison

The base strategy from Notebook 4 (SMA crossover) vs. five new strategies — MPT max-Sharpe, HFT Mean-Reversion Rebound, LSTM, NN, and (full universe only) an RL agent. Portfolio and benchmark lines all start at 1.0. HFT Mean-Reversion Rebound: buys a small fixed notional in a stock after a 1-day drop of 5%+ (daily bars only — this data has no intraday granularity, so it isn't literally high-frequency), can average in a second tranche on a further drop, and exits the full position only once price recovers to its pre-drop level. It has no stop-loss or max holding period — a stock that never recovers ties up capital indefinitely. Because the exit only fires above cost basis, every closed trade wins by construction; the strategy's real risk shows up as still-open, unrecovered positions and in the equity curve's drawdown, not in the win rate. LSTM / NN / RL — an important caveat: these three were actually TRAINED (on a 70/30 split, in lstm.ipynb, week2/01-features-and-model/notebook.ipynb, and scripts/run_train.py respectively), but this chart runs them across the WHOLE date range, including the days each one was trained on — unlike a proper held-out test. That's the same walk-forward chart SMA/MPT get (which never "train" and so have no leakage concern), applied uniformly for a fair visual comparison, but it means these three strategies' numbers here are optimistic versus a true out-of-sample result. The Model Comparison tab's charts, by contrast, show ONLY the held-out test period for NN and LSTM — that's the more honest number for those two.
